#### Featured

**[pyskyline](https://github.com/OlexanderPavliuk/pyskyline)** · [live demo](https://olexanderpavliuk.github.io/pyskyline/)

Turns a Python codebase into a 3D city. Every file is a building: its footprint is lines of code,
its height is cyclomatic complexity, and its color marks hotspots, where complex code also changes
most often. A Python CLI measures the project with `ast` and `git log`; a Three.js viewer renders it.
